  PHASE 4 — ADVANCED FEATURES (NEW)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  4.1  REAL-TIME TRANSLATION
  ─────────────────────────────────────────────────────────
  [ ] Add a "Translate" button next to the transcript
  [ ] Allow users to translate their transcript into any target language
  [ ] Use Groq/Llama API for translation (same pipeline as summarization)
  [ ] Show original + translated text side by side
  [ ] Support translating file upload results too
  Why: Users often record in one language but need the text in another.
       This turns VoiceScribe into a full transcription + translation tool.

  4.2  TRANSCRIPT SEARCH & HIGHLIGHTING
  ─────────────────────────────────────────────────────────
  [ ] Add a search bar inside the transcript panel
  [ ] Highlight matching words/phrases in real-time as user types
  [ ] Show match count ("3 of 12 matches")
  [ ] Navigate between matches with up/down arrows
  [ ] Search across all sessions in the History page
  Why: Long transcripts need searchability. This is essential for meetings
       that run 30+ minutes and generate hundreds of chunks.

  4.3  BOOKMARKS & TIMESTAMPS
  ─────────────────────────────────────────────────────────
  [ ] Allow users to "bookmark" important moments during recording
  [ ] Press a hotkey (e.g., Ctrl+B) to mark a timestamp
  [ ] Show bookmarks as markers on the audio player timeline
  [ ] Click a bookmark to jump to that point in the recording
  [ ] Bookmarks appear as highlighted chunks in the transcript
  Why: In long meetings, users need to flag key moments instantly
       without stopping to type notes.

  4.4  SPEAKER LABELS (Lightweight)
  ─────────────────────────────────────────────────────────
  [ ] Let users manually assign speaker names to transcript chunks
  [ ] Click a chunk → dropdown with "Speaker 1", "Speaker 2", etc.
  [ ] Color-code different speakers in the transcript
  [ ] Include speaker labels in exported text and summaries
  [ ] Remember speaker names per session
  Why: Full diarization requires GPU, but manual speaker tagging gives
       80% of the value with zero extra dependencies.

  4.5  CUSTOM VOCABULARY / HOTWORDS
  ─────────────────────────────────────────────────────────
  [ ] Settings page: add a "Custom Words" text area
  [ ] Users enter domain-specific terms (product names, jargon, names)
  [ ] Pass custom vocabulary to Whisper's initial_prompt parameter
  [ ] Improves accuracy for technical meetings and specialized domains
  [ ] Persist custom vocabulary per user/session in localStorage
  Why: Whisper often misspells proper nouns and technical terms.
       Custom vocabulary dramatically improves accuracy for specific use cases.

  4.6  SESSION TAGS & CATEGORIES
  ─────────────────────────────────────────────────────────
  [ ] Allow users to add tags to sessions (e.g., "meeting", "lecture", "interview")
  [ ] Predefined categories + custom tags
  [ ] Filter History page by tags
  [ ] Color-coded tag badges on session cards
  [ ] Analytics: breakdown by category (pie chart)
  Why: As users accumulate sessions, organization becomes critical.
       Tags make it easy to find and group related recordings.

  4.7  BATCH FILE PROCESSING
  ─────────────────────────────────────────────────────────
  [ ] Upload multiple files at once (up to 10)
  [ ] Show a queue with individual progress bars
  [ ] Process files sequentially to avoid overloading Whisper
  [ ] Generate a combined report or individual transcripts
  [ ] Download all results as a ZIP file
  Why: Users with existing recordings (interviews, lectures) often have
       many files to process. One-at-a-time is painfully slow.

  4.8  PDF & DOCX EXPORT
  ─────────────────────────────────────────────────────────
  [ ] Export transcript + summary as a formatted PDF
  [ ] Include session metadata (date, duration, language, speaker labels)
  [ ] Professional layout with headings, timestamps, and branding
  [ ] Also support DOCX export for editing in Word/Google Docs
  [ ] Add export options to History page (export past sessions)
  Why: TXT is too basic for professional use. PDF/DOCX exports make
       VoiceScribe output directly usable in business workflows.

  4.9  AUDIO TRIMMING & EDITING
  ─────────────────────────────────────────────────────────
  [ ] Select a time range on the audio player waveform
  [ ] Re-transcribe only the selected portion
  [ ] Delete/trim silent or irrelevant sections
  [ ] Split a long recording into smaller segments
  [ ] Export trimmed audio as a separate file
  Why: Recordings often have dead air, off-topic sections, or repeated
       content. Trimming lets users clean up before sharing.

  4.10 LIVE COLLABORATION & SHARING
  ─────────────────────────────────────────────────────────
  [ ] Generate a shareable link for any session
  [ ] Read-only view for shared sessions (no auth required)
  [ ] Real-time viewer count on shared sessions
  [ ] Viewers can see the transcript update live during recording
  [ ] QR code generation for quick sharing in meetings
  Why: In meetings, everyone needs access to the transcript. A shareable
       link eliminates "can you send me the notes?" completely.

  4.11 VOICE COMMANDS
  ─────────────────────────────────────────────────────────
  [ ] Detect special voice commands during recording
  [ ] "Add bookmark" → creates a bookmark at current timestamp
  [ ] "New paragraph" → inserts a visual break in the transcript
  [ ] "End session" → stops recording via voice
  [ ] Commands are filtered out of the final transcript
  Why: Hands-free control is essential when recording in situations
       where the keyboard isn't accessible (interviews, field work).

  4.12 EMAIL / SLACK INTEGRATION
  ─────────────────────────────────────────────────────────
  [ ] "Send via Email" button on completed sessions
  [ ] Enter recipient email → sends transcript + summary
  [ ] Slack webhook integration → post summary to a channel
  [ ] Support for Microsoft Teams webhook too
  [ ] Schedule automatic sends after each recording
  Why: Most meeting notes end up being sent to someone. Direct integration
       removes the copy-paste step entirely.

  4.13 RECORDING SCHEDULING
  ─────────────────────────────────────────────────────────
  [ ] Schedule a recording to start at a specific time
  [ ] Set duration limits ("stop after 30 minutes")
  [ ] Auto-summarize when the scheduled recording ends
  [ ] Desktop notification when scheduled recording starts
  [ ] Calendar view for upcoming scheduled recordings
  Why: Users who record recurring meetings can automate the flow.
       "Every Tuesday at 10am, record for 1 hour and email the summary."

  4.14 AUDIO ENHANCEMENT
  ─────────────────────────────────────────────────────────
  [ ] Noise reduction filter before sending audio to Whisper
  [ ] Echo cancellation for better accuracy
  [ ] Volume normalization for quiet speakers
  [ ] Background noise indicator ("noisy environment detected")
  [ ] Toggle enhancement on/off from the dashboard
  Why: Poor audio quality is the #1 cause of bad transcriptions.
       Pre-processing the audio before Whisper improves accuracy significantly.

  4.15 USAGE DASHBOARD & QUOTAS
  ─────────────────────────────────────────────────────────
  [ ] Track total recording minutes per day/week/month
  [ ] Track total Groq API calls and token usage
  [ ] Display cost estimates for API usage
  [ ] Set usage alerts ("notify me at 100 minutes/month")
  [ ] Export usage reports as CSV
  Why: For teams or paid deployments, usage tracking is essential.
       Users need to know how much they're consuming and at what cost.
